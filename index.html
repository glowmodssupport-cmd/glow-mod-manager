      How Glow behaves

      Safety & settings

      Review how Glow stores and deploys your packages.

      Game files and storage

      • Local library. Your mod library and settings are stored on this device.
      • Local ZIPs only. Import local Glow Mods ZIP packages containing glow-mod.json and a files/ folder.
      • Separate game copy. Glow copies selected mod files into its own game copy. Launch Original opens the executable you selected.
      • Disk space. Preparing a modded launch takes time and uses extra space for a separate game copy.
